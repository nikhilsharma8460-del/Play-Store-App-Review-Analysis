**Play Store App Review Analysis – What Drives App Success?**

**Project Overview**

This project focuses on Exploratory Data Analysis (EDA) of Google Play Store applications to understand the key factors that influence app success.

The analysis explores app characteristics, ratings, installs, reviews, pricing, categories, and user sentiment to identify patterns that contribute to app performance and user satisfaction.

The project uses Python to transform raw data into meaningful insights that can support data-driven business decisions.

**Business Problem**

With thousands of applications available on the Google Play Store, understanding what makes an application successful is important for app developers and businesses.

This project aims to answer:

* What factors influence app success?
* Which app categories attract more users?
* How do ratings and reviews reflect user satisfaction?
* Does app pricing influence app performance?
* What can user sentiment tell us about app quality?

**Project Objectives**

1. Understand the structure and characteristics of Google Play Store data.
2. Perform data cleaning and preprocessing.
3. Identify trends across app categories.
4. Analyze ratings, installs, reviews, and pricing.
5. Explore user sentiment through review analysis.
6. Identify factors associated with app success.
7. Present meaningful business insights and recommendations.

📊 Measuring App Success

App success is evaluated through three dimensions:

1. Reach: Number of app installations.
2. User Satisfaction: App ratings and review sentiment.
3. Engagement: Number of user reviews.
